## 📌 Problem 1: [125. Valid Palindrome](https://leetcode.com/problems/valid-palindrome/description/)

###  Problem Statement
A phrase is a **palindrome** if, after converting all uppercase letters into lowercase letters and removing all non-alphanumeric characters, it reads the same forward and backward. Alphanumeric characters include letters and numbers.

Given a string `s`, return `true` *if it is a palindrome, or* `false` *otherwise*.

---

###  Core Intuition & Approaches

#### Approach 1: Two Pointers In-Place (Optimal)
Instead of allocating a new filtered string, we can use two pointers (`left` starting at `0`, `right` starting at `s.length() - 1`):
1. **Skip Non-Alphanumeric Characters:** Advance `left` forward and `right` backward until both point to valid alphanumeric characters (or pass each other).
2. **Case-Insensitive Comparison:** Compare both characters converted to lowercase. If they mismatch, return `false`.
3. **Move Pointers:** Increment `left` and decrement `right`.
4. **Completion:** If the loop terminates without mismatches, the string is a valid palindrome, return `true`.

> [!TIP]
> **Why `static_cast<unsigned char>`?**  
> Functions like `std::isalnum` and `std::tolower` take an `int` parameter and expect values representable as `unsigned char` or `EOF`. On systems where `char` is signed, characters with values `< 0` (such as extended ASCII or special characters) trigger **Undefined Behavior**. Casting to `unsigned char` guarantees standard-compliant and safe execution.

---

###  C++ Implementation

```cpp
#include <iostream>
#include <string>
#include <cctype>
#include <algorithm>

using namespace std;

class Solution {
public:
    bool isPalindrome(string s) {
        // Base edge case: empty or single character is always a palindrome
        if (s.empty()) return true;

        int left = 0;
        int right = s.length() - 1;

        while (left < right) {
            // 1. Skip non-alphanumeric characters from left
            while (left < right && !isalnum(static_cast<unsigned char>(s[left]))) {
                left++;
            }

            // 2. Skip non-alphanumeric characters from right
            while (left < right && !isalnum(static_cast<unsigned char>(s[right]))) {
                right--;
            }

            // 3. Compare characters in lowercase
            if (tolower(static_cast<unsigned char>(s[left])) != 
                tolower(static_cast<unsigned char>(s[right]))) {
                return false;
            }

            left++;
            right--;
        }

        return true;
    }
};

```

#### Alternative: Clean string first with `std::transform` & `std::isalnum`
```cpp
class SolutionTransform {
public:
    bool isPalindrome(string s) {
        string filtered = "";
        for (char c : s) {
            if (isalnum(static_cast<unsigned char>(c))) {
                filtered += tolower(static_cast<unsigned char>(c));
            }
        }

        int i = 0, j = filtered.size() - 1;
        while (i < j) {
            if (filtered[i] != filtered[j]) return false;
            i++;
            j--;
        }
        return true;
    }
};

```

---

### ⏱️ Complexity Analysis
- **Time Complexity:** $\mathcal{O}(n)$ — each character is visited at most twice.
- **Space Complexity:** $\mathcal{O}(1)$ — pointers are updated in-place without extra string allocation.

## 📌 Problem 2: [977. Squares of a Sorted Array](https://leetcode.com/problems/squares-of-a-sorted-array/description/)

###  Problem Statement
Given an integer array `nums` sorted in **non-decreasing** order, return *an array of the squares of each number sorted in non-decreasing order*.

- **Example 1:**  
  - Input: `nums = [-4, -1, 0, 3, 10]`  
  - Output: `[0, 1, 9, 16, 100]`  
  - Explanation: After squaring, the array becomes `[16, 1, 0, 9, 100]`. After sorting, it becomes `[0, 1, 9, 16, 100]`.

- **Example 2:**  
  - Input: `nums = [-7, -3, 2, 3, 11]`  
  - Output: `[4, 9, 9, 49, 121]`

---

###  Core Intuition & Approaches

#### Why Simple Squaring + Sorting is Suboptimal:
- Squaring elements takes $\mathcal{O}(n)$, but sorting takes $\mathcal{O}(n \log n)$.
- We can achieve $\mathcal{O}(n)$ using the **Two Pointer Pattern**!

#### Two Pointer Approach ($\mathcal{O}(n)$):
1. Because the input array is already sorted, the **largest squares** must reside at the extremes:
   - Either the leftmost negative numbers (e.g., $(-10)^2 = 100$)
   - Or the rightmost positive numbers (e.g., $(10)^2 = 100$)
2. Place pointers at `left = 0` and `right = n - 1`.
3. Create a result vector of size $n$, and a pointer `idx = n - 1` to fill values from largest to smallest.
4. Compare $nums[left]^2$ with $nums[right]^2$:
   - Whichever is greater gets placed at `result[idx]`.
   - Move the corresponding pointer inward (`left++` or `right--`).
   - Decrement `idx--`.

---

### 💻 C++ Implementation

```cpp
#include <vector>
#include <cmath>

using namespace std;

class Solution {
public:
    vector<int> sortedSquares(vector<int>& nums) {
        int n = nums.size();
        vector<int> result(n);

        int left = 0;
        int right = n - 1;
        int idx = n - 1; // Fill from the largest square backwards

        while (left <= right) {
            int leftSquare = nums[left] * nums[left];
            int rightSquare = nums[right] * nums[right];

            if (leftSquare > rightSquare) {
                result[idx] = leftSquare;
                left++;
            } else {
                result[idx] = rightSquare;
                right--;
            }
            idx--;
        }

        return result;
    }
};

```

---

### ⏱️ Complexity Analysis
- **Time Complexity:** $\mathcal{O}(n)$ — each element is processed once.
- **Space Complexity:** $\mathcal{O}(n)$ — for the output array (or $\mathcal{O}(1)$ auxiliary space excluding result).

# 680 Valid Palindrome II
 Given a string s, return true if the s can be palindrome after deleting at most one character from it.

 

Example 1:

Input: s = "aba"
Output: true
Example 2:

Input: s = "abca"
Output: true
Explanation: You could delete the character 'c'.
Example 3:

Input: s = "abc"
Output: false

```cpp 
    class Solution {
public:
    bool palindromHelper(int i, int j, const string& s){
        while(i<j){
            if(s[i]!=s[j]){
                return false;
            }
            i= i+1;
            j= j-1;
        }
        return true;
    }
    bool validPalindrome(string s) {
       int left =0;
       int right = s.length()-1;
       
       while(left<right){
        
        if(s[left] != s[right]){
            return palindromHelper(left+1, right,s)|| palindromHelper(left, right-1,s);
        }else{
            left++;
            right--;
        }
        
    }
    return true;
    }
};
```
